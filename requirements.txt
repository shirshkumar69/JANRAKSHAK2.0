# JANRAKSHAK Requirements

## Core Requirements
- Flask-SocketIO for WebSocket real-time updates
- Chart.js for analytics visualizations
- Real-time data streaming every 5 seconds
- Session management and authentication
- Settings persistence

## Additional Python Dependencies
```
flask-socketio
python-engineio
python-socketio
chart.js
```

## WebSocket Events
- `connect` - Client connects
- `disconnect` - Client disconnects
- `update` - Real-time data push
- `alert` - Emergency alerts

## Installation Command
```bash
pip install flask-socketio python-engineio python-socketio
```
